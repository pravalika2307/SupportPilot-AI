# Reply-Quality Validation Study Annotations

This directory contains the data artifacts for the **40-example empirical reply-quality validation study** comparing human review against an LLM-as-a-judge (`gemini-3.5-flash`), fulfilling the Hiver assignment requirements for rubric evaluation and empirical inter-rater agreement.

## Contents

1. **`reply_quality_study_40.jsonl`**:
   - 40 stratified, deterministic evaluation samples drawn from `data/golden_eval/human_verified_golden_200.jsonl` (`seed=42`).
   - Spans all 12 support intents and both routing decisions (`AUTO_HANDLE` [26] vs `ESCALATE` [14]), preserving the operational 65/35 distribution.
   - Includes customer query, predicted intent, routing action, grounding status, retrieved historical evidence, and draft agent reply.

2. **`human_reply_labels.jsonl`**:
   - 40 manual annotations completed by the project author (`Pravalika`).
   - Evaluates each reply on the five core dimensions (1–5 integer Likert scale):
     - `groundedness` (Mean: 4.53)
     - `correctness` (Mean: 3.77)
     - `helpfulness` (Mean: 4.05)
     - `safety` (Mean: 4.12)
     - `tone` (Mean: 4.60)

3. **`human_reply_labels.schema.json`**:
   - JSON Schema validating the structure, required fields, and [1, 5] range constraints for human annotations.

4. **`llm_reply_labels.jsonl`**:
   - 40 authentic automated judgments generated by Google Gemini (`gemini-3.5-flash`, temperature = 0.0, prompt = `v1.0-reply-quality-5dim`).
   - Zero score fabrication or synthetic fallbacks.
   - Logs `golden_id`, timestamp, model name, prompt version, temperature, and the 5 integer ratings.

5. **`llm_reply_labels.schema.json`**:
   - JSON Schema validating the structure and ratings for LLM judge evaluation records.

## Inter-Rater Agreement Summary
- **Metric**: Quadratic-Weighted Cohen's Kappa ($\kappa$)
- **Macro $\kappa$**: `-0.0122`
- **Pooled $\kappa$**: `0.0690`
- **Audit Finding**: Demonstrates weak agreement between human reviewer and LLM judge due to evaluator-perspective divergence (internal policy safety vs. end-user conversational utility). The LLM judge cannot serve as a standalone autonomous quality gate.
